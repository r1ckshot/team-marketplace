# Security Policy

Плагіни в цьому marketplace виконуються з повними правами юзера. Sandbox
немає. Стався до кожного плагіна як до коду, який мержиш у прод.

## Review Policy

- Кожен плагін має одного названого мейнтейнера-схвалювача — поле `author`
  у `plugin.json` і в записі `marketplace.json`.
- PR, що додає або змінює плагін, потребує схвалення цього мейнтейнера.
- Зміни на рівні marketplace (`.claude-plugin/marketplace.json`, CI, цей
  файл) — окреме схвалення, той самий мейнтейнер (репо соло, ротації немає).

## PR Checklist

- [ ] Hooks переглянуті — кожна shell-команда й промпт навмисні й задокументовані
- [ ] `bin/` (якщо є) прочитаний повністю — без обфускованого payload
- [ ] Змінні середовища, які плагін читає, названі в README плагіна
- [ ] Мережеві виклики (якщо є) — названо адресу і що саме відправляється

## Без sandbox

Плагін бачить усе, що бачить юзер: файли, команди, мережу. Рев'ю відповідно.

## Репорт вразливості

`kapusticnyk.com@gmail.com` з описом і кроками відтворення. Без публічного
issue до підтвердження фіксу. Відповідь — протягом двох робочих днів.
